## 🛑 痛点分析：系统上线前的“至暗时刻”
在引入本系统之前，实验室饱受流程碎片化的折磨，并在应对 **ISO 9001:2015** 质量审核时面临极大的合规风险：
* **“放样即失联”综合征：** 送样人将样品扔在实验室后便离开，缺乏具体的测试要求、日期记录和联系人信息。
* **重复手写与识别灾难：** 化验员需要反反复复手写极为相似的测试模板，极易导致样品名称错漏、信息丢失和人工疲劳。
* **跨岗位协作混乱：** 同一个样品可能需要多人协作完成不同维度的测试。由于信息滞后，经常导致重复化验、优先级不明以及数据更新不及时。
* **失控的“样品山”：** 由于缺乏清晰的样品生命周期和清理追踪机制，测试完毕的废弃样品在实验室内长期堆积，占用大量空间。
* **合规性缺失：** 传统的纸质记录系统根本无法提供现代质量管理标准所强制要求的**透明度、可追溯性以及标准化的文档管理**。

## 🚀 核心价值：系统赋能后的数字化闭环
本系统作为一套严谨、数据驱动的数字化流水线，提供了降维打击般的解决方案：
1. **标准化模板引擎：** 预设标准测试模板，彻底告别手写盲区和主观错漏。
2. **秒级数字化建档：** 采样完成后，一键实例化生成数字“测试任务 (Job)”，与模板深度绑定。
3. **实时工作台 (矩阵看板)：** 采用直观的“红绿灯”矩阵追踪化验项状态（白色=未选，红色=必做，黄色=化验中，绿色=已审核），化验进度一目了然。
4. **动态优先级调度：** 核心工作队列支持鼠标拖拽 (Drag & Drop) 排序，化验室可随时根据生产紧急情况调整执行优先级。
5. **物理清理智能预警：** 独创的倒计时沙箱机制，样品过期后自动触发高亮警报，提醒化验员合规丢弃/清理物理样品，保障实验室环境5S。
6. **全流程留痕与追溯：** 所有的参数修改均强制要求填写操作人，数据深度存档，完美契合质量审核要求。

## 🛠️ 开源版核心技术特性
*为了保护原企业的核心商业机密，本开源版本已彻底切断真实的 SQL/C# 后端交互，并进行了深度的业务脱敏。*
* **100% 纯前端本地驱动：** 核心逻辑全面由 HTML/JS/CSS 构筑，结合 HTML5 `localStorage` 打造本地数据库闭环。无需配置任何后端环境，开箱即用。
* **业务参数高度抽象：** 原有的专有化学测试指标已被替换为通用参数（`Test A` - `Test F`），在完美展现交互逻辑的同时杜绝侵权风险。
* **附件虚拟流模拟：** 内置伪文件系统，模拟演示真实生产环境下的 PDF/图片附件验证与下载机制。
* **一键导出报表：** 系统支持根据当前看板数据，实时生成并导出纯净的 `.csv` 报表以供二次分析。

## 📥 运行指南
1. 下载或克隆本仓库到本地。
2. 在任意现代浏览器中双击打开 `index.html`。（为了获得最佳的跨页面数据同步体验，建议使用 VS Code 的 "Live Server" 插件，或直接通过 GitHub Pages 访问在线版本）。
3. 畅快体验：先去 `Template` 页面建一个模板，生成一个任务，然后在工作台里感受丝滑的数据录入吧！
